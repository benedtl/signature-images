Where to paste it

  1. Outlook for Windows (the classic app)File → Options → Mail → Signatures → New. Give it a name, click inside the big box, and press Ctrl+V. Set it as the default for new messages and replies, then click OK.
  2. New Outlook, or Outlook in a browserSettings → Accounts → Signatures → New signature, then press Ctrl+V and save.
  3. GmailSettings → See all settings → Signature → Create new, then press Ctrl+V and save changes at the bottom of the page.
  4. Apple MailMail → Settings → Signatures, add one, and paste. Untick “Always match my default message font”.

Send yourself a test message afterwards. Pictures can take a moment to appear the first time.
